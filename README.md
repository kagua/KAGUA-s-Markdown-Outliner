# KAGUA's Markdown Outliner

Markdownファイルを、章・節・項目のツリー形式で整理・編集するためのシンプルなアウトラインプロセッサです。

## 特徴

- 登録不要
- 完全無料
- 広告なし
- AIによる学習・解析なし
- Markdown（`.md` / `.markdown`）を読み込み・保存
- ドラッグ＆ドロップでトピックを移動
- トピックの階層を変更可能
- ブラウザ上で動作し、サーバーへのアップロードは不要

## 使い方

1. `index.html` を Chrome / Edge で開く
2. 「開く」で Markdown ファイルを読み込む
3. アウトラインを編集する
4. 「保存」で Markdown ファイルとして保存する

## 主な操作

- ＋ : 同じ階層にトピック追加
- 子 : 子トピック追加
- ↑ ↓ : 同じ階層で移動
- ← → : 階層を変更
- × : トピック削除
- ドラッグ : トピックを移動
- Enter : 同じ階層に追加
- Tab / Shift+Tab : 階層変更
- Ctrl+S : 保存

## Markdown出力

- ATX形式（`# 見出し`）で出力
- 本文と見出しの間を空行で区切る
- 本文の最後にも空行を1行入れる

## 保存について

このアプリには、下書きや履歴などをユーザーが任意に指定して保存する一時保存機能はありません。

編集した内容を残す場合は、「保存」を実行して Markdown ファイルとして保存してください。

ブラウザを閉じたり、ページを再読み込みしたりする前に、必要な内容を保存してください。

## 外部ライブラリ

ドラッグ＆ドロップ機能に SortableJS 1.15.7 を使用しています。

現在の `index.html` は CDN から SortableJS を読み込む構成です。そのため、ドラッグ＆ドロップ機能の利用にはインターネット接続が必要です。
